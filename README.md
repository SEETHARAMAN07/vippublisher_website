# VIP PUBLICATIONS - Notebook & Stationery Manufacturing Website

Official web portal for **VIP PUBLICATIONS**, premier manufacturer and bulk supplier of notebooks, office registers, writing pads, and custom institutional stationery based in Sivakasi, Tamil Nadu, India.

---

## 🚀 Features

- **Modern Responsive Design**: Built with React 19, Vite, and modern CSS.
- **Product Showcase**: Detailed specifications for School Notebooks, Corporate Stationery, Drawing Books, Practical Records, and Custom Stationery.
- **Custom Order & Quotation Form**: Comprehensive quote calculator and enquiry flow for bulk buyers and institutions.
- **Company Profile & Facility Tour**: Showcases infrastructure, manufacturing processes, and quality standards.
- **Fast Performance**: Instant page loads powered by Vite bundling and optimized assets.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router v7
- **Icons**: Lucide React
- **Build Tool**: Vite 6
- **Styling**: Vanilla CSS (Custom Design System with responsive tokens)

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18 or higher) installed.

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd com-web
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173` to view the application.

### Building for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
